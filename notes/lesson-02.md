# Lesson 02 — Git & Collaboration notes

- Branches isolate experiments; merge brings them back into main
- CRLF/LF: cloned on Windows, files showed as all-modified; fixed with core.autocrlf input + git checkout .
- Fork workflow: origin = my fork (push here), upstream = course repo (pull updates, never push)
